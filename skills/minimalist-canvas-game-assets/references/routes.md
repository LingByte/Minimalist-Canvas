# 选路

先确认交付物是**静态设定图**还是**可播放动作序列**，再选参考。已有明确画风 / 尺寸 / 动作范围时沿用，只加载当前任务所需文档。

| 用户目标 | 做法 | 参考 |
| --- | --- | --- |
| 一张角色立绘 / 设定图 | 文生图或带参考的图生图；透明底按需 | [提示词模式](prompt-patterns.md) |
| 三视图 / 转身选帧 / 八方向朝向 | 先出正面设定，再补方向；Codex 亲自看图选朝向 | [角色表](character-sheet.md) |
| 一套走跑待机攻击（或子集） | 五向 + 镜像，或八向分别生成 | [动作包](action-pack.md) |
| 技能特效、命中闪、buff 环 | 单帧或短序列；透明底 | [特效与道具](effects-props.md) |
| 道具、武器、UI 图标、地砖 | 静态图；注明俯视/等距/侧视 | [特效与道具](effects-props.md) |
| 短剧人物造型拆解（不生图） | 交给 `short-drama-assets`，不要用本 skill | — |
| 纯通用生图/视频、无游戏结构 | 交给 `minimalist-canvas-media` | — |

## 共用规则

- 生成前写清：画风、分辨率或像素预算、透明底、方向数、动作列表、输出根目录。
- 批量任务先列计划与大致张数，再逐张提交；用户说「再试试」是改需求，不是无限重跑。
- 镜像会翻转左右手与单侧配件；不对称角色必须八向实拍/实生成。
- 验收看：朝向正确、同角色一致、轮廓完整、走/跑可区分、待机稳定、攻击过程完整。
