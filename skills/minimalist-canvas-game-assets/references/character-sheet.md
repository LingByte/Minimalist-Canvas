# 角色表 · 三视图与八方向

## 目标

为后续动作包准备一致的朝向参考：正面、背面、左侧（及斜向），画布留边足够，优先透明底。

## 流程

1. **定角色**：描述或参考图 → 生成 1–3 张候选设定图，展示后选定（用户未指定时取最清晰、轮廓完整的一张）。
2. **定方向方案**
   - **完美八方向**：分别生成或一次 sheet 出八向；四方向取前/后/左/右。
   - **转身选帧**：先生成一圈转身序列/拼图，**亲自看图**按实际朝向挑 4 或 8 帧，禁止均匀抽帧或复制首帧凑数。
3. **默认五向输入**：`front` · `back` · `left` · `frontLeft` · `backLeft`；右侧三向用 `game-assets.mjs mirror` 补齐。
4. **落盘**：写入 `directions/`，文件名用英文朝向键，保留原图。

## 提示词要点

- 固定：同一角色、同一服装与体型、游戏精灵/HD2D/像素（按用户画风）、正交或轻微 3/4、全身入画、居中、透明背景。
- 每张只改朝向词：`facing camera` / `back view` / `facing left` / `front-left three-quarter` / `back-left three-quarter`。
- 像素风写明像素网格与禁抗锯齿；HD2D 写明清晰描边与稳定色块。

## 验收

- 朝向可一眼辨认；左右脚/持物在镜像前与「左」侧一致。
- 头身比、配色、道具与设定图一致。
- 透明边缘无大块脏边；超出像素预算时报尺寸并停下。
