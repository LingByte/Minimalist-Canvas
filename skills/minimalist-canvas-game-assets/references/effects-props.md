# 特效 · 道具 · 场景块

## 特效

- 写清：元素类型（火/冰/斩击/治疗环…）、时长感（爆发 / 循环）、是否需要透明底、俯视还是侧视。
- 序列：保持同一锚点与画布尺寸，便于引擎挂点。
- 不要把角色动作包提示词套到纯特效上。

## 道具 / 武器 / UI

- 单件居中、完整轮廓；武器注明握持朝向。
- 图标类可要求「UI icon, readable at 64px」。
- 与角色同画风；需要成套时固定色板关键词。

## 地砖 / 场景块

- 写明投影：顶视、2:1 等距、侧视平台。
- 无缝贴图时要求 seamless tile；验收时检查对边能否拼接。

## 输出

建议 `effects/<name>/` 或 `props/<name>.png`；多帧时附简单 `frames.txt` 或写入角色 `manifest.json` 的 `effects` 段。
